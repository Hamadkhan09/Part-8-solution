# University of Helsinki: Java Programming MOOC ☕

This repository contains my personal solutions for the [Java Programming MOOC](https://java-programming.mooc.fi/) offered by the University of Helsinki. 

Currently, this repository highlights my progress starting from **Part 8** (the beginning of Java Programming II), where the course transitions into advanced Object-Oriented Programming (OOP) and application architecture.

## 🛠️ Concepts Conquered (Part 8)
In this section, I focused on fast data retrieval and writing clean, scalable application architecture:
* **Advanced Data Structures:** Extensive use of `HashMap` for constant-time data lookup (e.g., `VehicleRegistry`, `StorageFacility`).
* **Object Grouping:** Utilizing Maps and Lists together to group and manage complex datasets.
* **Separation of Concerns:** Separating the User Interface (UI) from the core application logic to make the code cleaner and more maintainable.
* **Custom Object Hashing:** Overriding `equals()` and `hashCode()` methods to allow custom objects to be used as keys in a HashMap.
